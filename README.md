# 🚀 Featured Projects

## 🚦 [Traffic Violation Detection System](https://github.com/kvshashankpai/Traffic_Violation)

Real-time computer-vision pipeline for detecting **six traffic-violation categories** using YOLO-based models, depth estimation, rider-vehicle association, and Indian-format automatic license-plate recognition.

**Highlights**
- YOLOv8s + Depth Anything V2 + YOLOv11
- Depth- and IoU-guided rider-to-vehicle association
- FSRCNN ×3 super-resolution + CLAHE
- PaddleOCR / PP-OCRv5 with position-aware correction
- ~0.4s frame inference reported in the project work

---

## 🌐 [English → Hindi Neural Machine Translation](https://github.com/kvshashankpai/TransformerEngHind)

A **59.4M-parameter Transformer encoder-decoder implemented from scratch in PyTorch** for English-to-Hindi translation.

**Highlights**
- 6 encoder + 6 decoder layers
- 8 attention heads
- d_model = 512
- Custom 10K-vocabulary BPE tokenizers
- 100,000 IIT Bombay corpus sentence pairs
- Label-smoothed cross-entropy + Adam
- Baseline BLEU: 3.12

---

## 📄 [Document Intelligence System](https://github.com/kvshashankpai/pdf-intelligence)

Cross-document intelligence system for searching, comparing, and extracting insights from collections of PDFs.

**Highlights**
- Semantic search across 25–30 PDFs
- Heading classification with Random Forest
- SentenceTransformer embeddings
- MMR-based relevance/diversity ranking
- Contradiction detection
- Persona-driven retrieval
- Gemini 2.5 Flash grounded generation
- 88% relevance accuracy with sub-10-second response time
